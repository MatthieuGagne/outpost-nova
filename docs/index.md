# Outpost Nova — Documentation Index

This is the catalog of every design, story, world, and character document in `docs/`. It exists so anything written down can be found at a glance — it does not replace or summarise the documents it lists.

**Rule:** any new doc added under `docs/` gets a line here, in the section matching its directory.
